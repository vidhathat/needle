# Contributing

Thanks for helping improve Needle.

1. Fork the repository and create a focused branch.
2. Run `npm install`, `npm test`, and `npm run lint` before opening a pull request.
3. Keep media assets original or include clear redistribution terms.
4. Do not commit signing certificates, Apple credentials, Vercel tokens, or
   music protected by copyright.

By contributing, you agree that your contribution is distributed under the
MIT License.
